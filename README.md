# ✅ Lista de Tarefas (To-Do List)

Uma **aplicação web de lista de tarefas** desenvolvida com **HTML, CSS e JavaScript puro**, que permite ao usuário **organizar, editar, filtrar e salvar tarefas**, com suporte a **modo claro/escuro** e **persistência de dados via `localStorage`**.

Projeto focado em **lógica de programação**, **manipulação do DOM**, **experiência do usuário (UX)** e **boas práticas de front-end**.

## 🧠 Como Funciona

1️⃣ O usuário digita uma nova tarefa no campo de entrada  
2️⃣ Ao clicar em **Adicionar**, a tarefa é incluída na lista  

Cada tarefa pode ser:
- ✏️ Editada  
- ✅ Marcada como concluída  
- ❌ Removida  

🔍 Os filtros permitem visualizar tarefas específicas conforme o status  

💾 Todas as alterações são salvas automaticamente no navegador  

🔄 Ao recarregar a página:
- As tarefas são restauradas  
- O estado de cada tarefa é mantido

## 💾 Persistência de Dados

As tarefas são armazenadas no navegador usando **`localStorage`**, permitindo que:

📌 Nenhuma tarefa seja perdida  
📌 O estado (concluída ou não) seja mantido  
📌 Os dados persistam mesmo após fechar o navegador
